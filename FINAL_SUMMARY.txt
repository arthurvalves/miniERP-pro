🎓 COMO USAR O NOVO SISTEMA
═══════════════════════════════════════════════════════════════════════════════════════

Para migrar um novo view para o novo design:

```python
# 1. Importar tema
from erp_frontend.theme import COLORS, SPACING, ThemeManager

# 2. Usar fundo do tema
super().__init__(master, fg_color=COLORS["bg_dark"])

# 3. Usar espaçamento
self.pack(padx=SPACING["xl"], pady=SPACING["xl"])

# 4. Usar componentes com estilo pronto
button = ctk.CTkButton(
    parent,
    text="Ação",
    **ThemeManager.get_button_style("primary")  # ← Estilo pronto!
)

# 5. Usar paletas para dados
card = ctk.CTkFrame(
    parent,
    **ThemeManager.get_card_style()  # ← Card pronto!
)
```

Veja exemplos completos em:
  • dashboard_view.py (como usar cores e cards)
  • README_DESIGN.md (guia prático)


📞 DÚVIDAS FREQUENTES
═══════════════════════════════════════════════════════════════════════════════════════

P: Por que 5 cores?
R: Guidelines de design recomendam 3-5 cores para coesão visual.

P: Posso mudar as cores?
R: Sim! Edite COLORS dict em theme.py e todas as views se atualizam.

P: Como adicionar uma nova paleta?
R: Adicione em PALETTES em theme.py, depois use no componente.

P: Funciona em Linux/Mac/Windows?
R: Tkinter é cross-platform. Testado em Windows, rodar em outros OSs.

P: Posso usar em outros projetos Python?
R: Sim! O theme.py é independente e reutilizável.

P: Quando migro os outros views?
R: Veja PRÓXIMAS ETAPAS acima. Comece por pdv_view.py.
