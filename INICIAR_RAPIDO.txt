OPÇÃO 1: MODO SUPER RÁPIDO (Recomendado)
═════════════════════════════════════════════════════════════════════

Windows:
--------
1. Abra o gerenciador de arquivos
2. Acesse a pasta do projeto (miniERP-pro)
3. Clique 2x no arquivo "iniciar.bat"
4. Aguarde 30-60 segundos
5. A aplicação abrirá automaticamente

macOS/Linux:
----------
1. Abra o terminal
2. Navegue para a pasta: cd ~/miniERP-pro
3. Execute: chmod +x iniciar.sh && ./iniciar.sh
4. Aguarde 30-60 segundos
5. A aplicação abrirá automaticamente


OPÇÃO 2: MANUAL (Se der problema)
═════════════════════════════════════════════════════════════════════

Passo 1: Abrir terminal/CMD
─────────────────────────────
Windows: Pressione Win+R, digite "cmd" e Enter
macOS/Linux: Abra o Terminal

Passo 2: Navegar para a pasta
──────────────────────────────
cd caminho/para/miniERP-pro

Passo 3: Criar ambiente virtual (primeira vez)
──────────────────────────────────────────────
Windows:
  python -m venv venv
  venv\Scripts\activate

macOS/Linux:
  python3 -m venv venv
  source venv/bin/activate

Passo 4: Instalar dependências (primeira vez)
──────────────────────────────────────────────
pip install -r requirements.txt

Passo 5: Rodar a aplicação
───────────────────────────
Windows:
  python erp_frontend/main_window.py

macOS/Linux:
  python3 erp_frontend/main_window.py


PROBLEMAS COMUNS E SOLUÇÕES
═════════════════════════════════════════════════════════════════════

❌ "Python não encontrado"
────────────────────────────
Solução: Instale Python de https://www.python.org/downloads/
Ao instalar, MARQUE "Add Python to PATH"

❌ "ModuleNotFoundError: customtkinter"
────────────────────────────────────────
Solução: Digite no terminal:
  pip install customtkinter --upgrade

❌ "Arquivo .bat não executa"
────────────────────────────
Solução: 
1. Clique com botão direito em iniciar.bat
2. Selecione "Executar como administrador"

❌ "Permissão negada ao executar .sh (macOS/Linux)"
────────────────────────────────────────────────────
Solução: No terminal, execute:
  chmod +x iniciar.sh
  ./iniciar.sh

❌ "Aplicação lenta na primeira vez"
─────────────────────────────────────
É normal! Primeira execução é mais lenta.
Deixe a aplicação abrir completamente (pode levar 1-2 minutos).
