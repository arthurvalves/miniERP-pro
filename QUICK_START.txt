═════════════════════════════════════════════════════════════════════════════════

1. python -m venv venv
2. source venv/bin/activate (ou venv\Scripts\activate no Windows)
3. pip install -r requirements.txt
4. python erp_frontend/main_window.py

⚙️ PERSONALIZAÇÃO
═════════════════════════════════════════════════════════════════════════════════

Mudar Cores:
  Edite: erp_frontend/theme.py
  Linha: COLORS = {...}

Mudar Tamanho da Janela:
  Edite: erp_frontend/main_window.py
  Procure: self.geometry("1400x900")

Adicionar Novo Menu:
  Edite: erp_frontend/main_window.py
  Função: _create_sidebar_menu()

Novo Card no Dashboard:
  Edite: erp_frontend/dashboard_view.py
  Veja: _create_card()


🐛 PROBLEMAS COMUNS
═════════════════════════════════════════════════════════════════════════════════

"Python não encontrado"
  → Instale em: https://www.python.org/downloads/

"customtkinter não encontrado"
  → pip install customtkinter --upgrade

"Erro de banco de dados"
  → Primeira execução pode demorar
  → Deixe a aplicação abrir completamente

"Interface em branco"
  → Aguarde alguns segundos
  → Pode estar inicializando
